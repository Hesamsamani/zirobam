# مربی نت‌خوانی (Music Notes Trainer)

این پروژه شاخه‌ای شخصی و آموزشی از برنامهٔ [ftrain/sightreading](https://github.com/ftrain/sightreading) است. هدفش این است که یک مبتدی بتواند با رابط انگلیسی یا فارسی، چه با کیبورد MIDI و چه بدون آن، نت‌خوانی را یاد بگیرد. نسخهٔ انگلیسی این راهنما در [README.md](README.md) است.

## این شاخه چه چیزی اضافه می‌کند

کار هنوز در جریان است و فهرست زیر هدف نسخهٔ اول است.

- رابط انگلیسی و فارسی، با چیدمان راست‌به‌چپ برای متن فارسی. حامل نت و کیبورد پیانو همچنان چپ‌به‌راست می‌مانند، چون نت‌نویسی و پیانو همیشه از چپ به راست خوانده می‌شوند.
- نام نت‌ها به سه شکل: حرفی (C D E)، سولفژ لاتین (Do Re Mi) و سولفژ فارسی (دو ر می).
- نواختن بدون کیبورد MIDI، با پیانوی روی صفحه و صفحه‌کلید رایانه.
- حالت «نام نت را بگو» برای مبتدی‌ها، همراه با درس‌های کوتاه و تمرین بیشتر روی نت‌هایی که اشتباه خوانده شده‌اند.
- برنامه‌ریزی‌شده برای نسخهٔ بعد: ورودی میکروفون برای ساز آکوستیک.

## اجرای برنامه

نصب و اجرا به Node.js نیاز دارد:

```bash
npm ci
npm run dev
```

آدرس برنامه بعد از اجرا: `http://localhost:5173/sightreading/`

برای اجرای آزمون‌ها از دستور `npm test` استفاده کنید.
